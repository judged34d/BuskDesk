# Bewegung: Licon 1 vs Busk Desk

## Was die Licon 1 laut Handbuch macht

JB-Lighting Licon 1 (Handbuch §5.2) bietet **vorprogrammierte** Moving-Patterns:

- Kreis, Lissajous, Auf/Ab, Links/Rechts, Diagonal
- Size / Speed / Phase (Welle über mehrere Heads)
- Speichern als Preset

Das ist geometrisch und gut für effektvolle Busking-Shows.

## Was du am Pult erinnerst (und wir bauen)

1. Spot auf Position **A** (Start)  
2. Spot auf Position **B** (Ende)  
3. Speichern als Bewegung  
4. Taste → hin und her, mit aktueller Geschwindigkeit  
5. Optional Farbe / Gobo / Dimmer / Strobe im Pattern  

Das ist für kleine Bühnen oft nützlicher als Kreis-Lissajous: z. B. „zwischen Rednerpult und Band hin und her“.

## Busk Desk (schlank)

| Funktion | Umsetzung |
| --- | --- |
| Fokuspunkte | Pfeiltasten Pan/Tilt, speichern/abrufen |
| Pattern A↔B | Mark A, Mark B, Look-Checkboxen, Play/Stop |
| Nicht (vorerst) | Licon-Kreise, Phasenwelle über 32 Heads |

Quelle Handbuch: [Licon 1 Manual (JB-Lighting)](https://www.jb-lighting.de/download/Handbuch/Licon_1_Manual.pdf)
